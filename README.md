# cast_app_web

Cast app(軽量な画面共有)の Web 版を公開するためのリポジトリです。
https://mantisnorinn-hue.github.io/cast_app_web/ を開くと、そのまま使えます。

- ウィンドウまたは全画面を選んで共有し、6 文字の参加コードで視聴します。
- 映像は端末どうしが直接やり取りします。接続の取り次ぎには、無料の公開サービス PeerJS(0.peerjs.com)を使います。
- ⚠ 接続のときに、IP アドレスなどの接続情報が PeerJS を通ります。

このリポジトリの中身は、非公開の本体リポジトリの `web/` をコピーしたものです。直接編集しないでください。
